# Commercial Boundary

This repository is the open-source research layer of the broader SceneScoutAI concept.

## Open-source components

This repository may include:

- Metadata schemas.
- Example workflows.
- Prompt templates.
- Documentation.
- Educational demos.
- Synthetic sample data.
- Reference package-planning structures.

## Proprietary components

The following may remain proprietary:

- Hosted SceneScoutAI SaaS platform.
- Production backend.
- Customer data systems.
- Authentication and account management.
- Private newsroom integrations.
- Deployment infrastructure.
- Enterprise admin tools.
- Commercial workflow engine.
- UI/UX implementation.
- Customer-specific model tuning.
- Paid support and managed services.

## Business model compatibility

This project can remain open source while the maintainer earns revenue through:

- Hosted software.
- Enterprise licensing.
- Private deployments.
- Managed compute workflows.
- Customer support.
- Custom integrations.
- Compliance and security features.
- Training and implementation services.
