# Contributing

Thanks for considering a contribution.

This repository exists to explore archive-aware generative media workflows for newsrooms and production teams.

## Good contributions

Good contributions include:

- Metadata schema improvements.
- Example scripts and sample package plans.
- Responsible AI workflow recommendations.
- Documentation improvements.
- Prompt templates for archive-aware media generation.
- Test cases using synthetic or public-domain sample data.
- Accessibility and editorial transparency improvements.

## Do not submit

Please do not submit:

- Private newsroom footage.
- Customer scripts.
- Real anchor likenesses without explicit permission.
- Confidential production workflows.
- Private API keys.
- Scraped copyrighted media assets.
- Any material you do not have the right to share.

## Pull request process

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Add or update examples/tests where useful.
5. Open a pull request with a clear explanation.

## Editorial safety

All examples should assume that generated media is subject to human review before publication.
