# Commercial Boundary

This toolkit is open source. The full SceneScoutAI product does not have to be.

## Open

- Schemas
- Examples
- Documentation
- Research workflows
- Synthetic demo data
- Prompt patterns

## Private or commercial

- Hosted app
- Customer accounts
- Private integrations
- Production orchestration
- Deployment infrastructure
- Enterprise features
- Customer-specific training
- Managed services
